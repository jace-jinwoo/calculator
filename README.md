# 계산기 모음 (Next.js 정적 웹사이트)

DB와 외부 API 없이 브라우저에서 바로 계산되는 정적 웹사이트입니다.

## 포함 계산기

- 실업급여, 연차수당, 퇴직금, 주휴수당, 시급→월급, 실수령액 간이 계산
- 만 나이, D-Day, 전역일
- 환율(직접 환율 입력), 대출 월 상환액, 예금 복리, 퍼센트, 부가세
- 단위 변환(평/m², °C/°F, 길이, 무게, 데이터), BMI

## 실행 방법

```bash
npm install
npm run dev
```

브라우저에서 http://localhost:3000 을 열세요.

## 정적 배포용 빌드

```bash
npm run build
```

빌드가 끝나면 `out/` 폴더가 생성됩니다. 이 폴더를 Vercel, Netlify, Cloudflare Pages, GitHub Pages, S3 등 정적 호스팅에 업로드하면 됩니다.

## 참고

- 환율 계산기는 외부 API 없이 동작하도록 현재 환율을 직접 입력하는 방식입니다.
- 노무 관련 계산 결과는 법적 효력이 있는 확정 금액이 아니며, 최신 기준과 개인별 조건에 따라 달라질 수 있습니다.
